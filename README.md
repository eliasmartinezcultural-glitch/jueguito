# Jueguito — Los secretos del agua

Primer prototipo jugable de un RPG educativo ambientado en San Patricio del Chañar, Neuquén.

## Cómo jugar
- Abrí `index.html` en un navegador moderno o publicá el repositorio con GitHub Pages.
- Caminá con flechas o WASD.
- Acercate a personajes y objetos y presioná **E** o **Espacio** para interactuar.
- En celular, usá los botones de dirección.
- El cuaderno reúne las pistas y el progreso se guarda en el navegador del dispositivo.

## Tecnología
HTML, CSS y JavaScript nativos; canvas para el mapa pixel art. Sin frameworks, cuentas, servidores, dependencias ni servicios pagos.

## Qué incluye esta primera versión
- Vista desde arriba.
- Mapa exploratorio con río, canal, casa y chacra.
- Tres interacciones con preguntas educativas.
- Cuaderno de pistas, progreso y guardado local.
- Controles para teclado y pantalla táctil.

## Criterio histórico
Los personajes y diálogos son ficticios y didácticos. No representan testimonios reales. Los hitos históricos se separan de la ficción y se deben ampliar con documentos originales, mapas y testimonios autorizados.
